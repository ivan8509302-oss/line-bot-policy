LINE歸檔機器人 隱私權政策

最後更新：2026-10-21

1. 收集哪些資料

機器人只處理它所在的 LINE 聊天室（被加入的群組、直接傳給它的一對一訊息）中的：文字訊息、照片、文件檔，以及聊天室名稱與傳送者的 LINE 顯示名稱。機器人不在的聊天室，它看不到。

2. 資料用途與存放位置

上述資料只用來在擁有者本人的 Google 雲端硬碟建立歸檔（依聊天室與月份分資料夾、每日逐條紀錄）。資料存放在擁有者的 Google 雲端硬碟；處理過程經過 Google Cloud 的伺服器，不另外建立資料庫。

3. Google 使用者資料

本應用程式只向 Google 要求 https://www.googleapis.com/auth/drive.file 權限，只能建立與存取它自己建立的檔案與資料夾，看不到雲端硬碟裡的其他檔案。從 Google API 取得的資料只用於上述歸檔功能，不出售、不提供給第三方、不用於廣告。本應用程式對 Google API 所取得資料的使用，遵守 Google API 服務使用者資料政策，包括「有限使用」規定。

4. 分享

不與任何第三方分享資料。

5. 保存與刪除

歸檔檔案保存在擁有者的雲端硬碟，由擁有者自行管理與刪除。把機器人移出聊天室後，就不再收任何新訊息。擁有者可隨時到 Google 帳戶的第三方存取權 撤銷授權。
